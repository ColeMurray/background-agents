Open-Inspect · Design Overview

Let parents steer child sessions.

A small, secure extension that turns one-shot child tasks into durable, steerable working sessions.

Direct children only Durable FIFO queue No new agent transport

01 · The gap

Today, child tasks are effectively one-shot.

Current Spawn. Wait. Read.

The parent can create, inspect, or cancel a child, but cannot add context to the same child session.

spawn-child → get-child-status
↳ new work? spawn another child
vs.
Proposed Spawn. Inspect. Steer.

The parent can queue a follow-up into the child's existing conversation and workspace.

send-child-prompt(childId, prompt)
↳ same child, same context
02 · The solution

One tool. One route. The existing queue.

01 / TOOL

`send-child-prompt`

The parent supplies a direct child ID and follow-up text.

02 / CONTROL PLANE

Parent-scoped route

Authenticates the parent sandbox and proves direct lineage twice.

03 / CHILD

Normal prompt queue

Persists the prompt, restores the sandbox if needed, then executes in order.

03 · Request flow

The follow-up becomes a normal child turn.

Prompt queuePersist, restore, execute
Important: this is queued steering, not interruption. If the child is already working, the follow-up runs next. The successful response means “durably queued,” not “finished.”
04 · Trust boundary

The parent never receives the child’s credential.

1Validate token against the parent session
2Confirm direct lineage in the D1 index
3Confirm parent ID again inside the child DO
4Resolve the child owner locally
5Persist with source = agent
“Authority follows the parent path, not a supplied identity.”

The caller cannot forge an author, target an unrelated child, or reuse the parent token against the child’s ordinary prompt endpoint.

05 · Lifecycle

Useful states resume. Terminal states stay terminal.

CREATED

Accept and queue after the initial prompt.

ACTIVE

Accept and append to the FIFO queue.

COMPLETED

Reactivate and restore from a compatible snapshot.

FAILED

Reactivate so the parent can provide recovery instructions.

CANCELLED

Reject with 409. Cancellation remains terminal.

ARCHIVED

Reject with 409 until explicitly unarchived.

06 · Change surface

Message source and owner attribution

07 · Guardrails

Bounded authority, predictable behavior.

64K

Prompt size

Content-only requests are capped at 64,000 characters.

10

Queue depth

A child accepts at most 10 pending or processing turns.

↻

Resume capacity

Completed and failed children honor existing concurrent-child limits.

No extras

No attachments, model overrides, callbacks, or arbitrary descendants in v1.
