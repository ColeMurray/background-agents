## One lifecycle

The core workflow is consistent across the web application and integrations:

1. Choose a repository and environment.
2. Describe the work and how to validate it.
3. Let the agent work in an isolated sandbox.
4. Monitor the shared timeline and provide follow-up context when needed.
5. Review the evidence and code changes.
6. Decide whether to iterate, open a pull request, or take over.

OpenInspect creates proposed changes. Your repository's review and merge policies remain the
final authority.
